# Ember & Oak Coffee ☕

A responsive coffee shop website concept built with HTML, CSS, and vanilla JavaScript. The design pairs warm editorial typography with earthy colors, immersive photography, and a clean, modern layout.

## Preview

The website includes:
- Responsive navigation with a mobile menu
- Hero section and brand story
- Interactive menu filters for coffee, tea, and bakery items
- Café feature section and location details
- Newsletter form interaction (front-end demo only)
- Responsive layouts for desktop, tablet, and mobile
- Accessibility details such as semantic sections, form labels, and reduced-motion support

## Built With

- **HTML5** — semantic page structure
- **CSS3** — responsive layout, custom properties, transitions, and typography
- **JavaScript** — mobile navigation, menu filtering, and demo form feedback
- **Google Fonts** — Playfair Display and DM Sans
- **Unsplash** — remote photography

## Getting Started

No build tools or dependencies are required.

1. Download or clone this repository.
2. Open `index.html` in your browser.

For the best local development experience, use the **Live Server** extension in Visual Studio Code.

## Project Structure

## Customize the Project

- **Brand and copy:** edit the text in `index.html`.
- **Colors and typography:** update the CSS variables at the top of `style.css`.
- **Menu items and prices:** edit the menu cards in `index.html`.
- **Photography:** replace the Unsplash image URLs in `style.css` and `index.html`.
- **Location and hours:** update the address, opening hours, and directions link in `index.html`.

## Important Notes

This is a front-end portfolio demo. The newsletter form does not send or store email addresses; connect it to a backend or email marketing service before using it in production. The café name, address, menu, and prices are fictional sample content. Images and Google Fonts are loaded from external services, so an internet connection is needed for those assets.

## Deploy with GitHub Pages

1. Create a new repository on GitHub.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder, then click **Save**.
6. Wait for GitHub Pages to publish your site. Your public URL will appear in the Pages section.
